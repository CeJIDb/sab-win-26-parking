# docs/assets — бинарные ассеты витрины

Хранилище бинарных файлов, которые используются в визуальном представлении репозитория: OG-image для Social Preview, логотипы, баннеры и подобные файлы.

## Назначение

Файлы из этого каталога не редактируются напрямую в репозитории — они готовятся внешними инструментами (Figma, Canva, Miro) и кладутся сюда как готовые артефакты.

## Текущие файлы

- `social-preview.png` — OG-image для GitHub Social Preview (1200×630, PNG, ≤ 1 МБ). Загружается вручную через GitHub Settings → General → Social Preview.

Процедура обновления OG-image и переименования Netlify-сабдомена: [docs/process/branding-checklist.md](../process/branding-checklist.md).
