## Назначение

Документ нужен, чтобы:

- зафиксировать согласованный формат `POST /api/v1/contracts` для UC-8.2;
- дать разработчику и QA каноничные примеры для реализации и проверок;
- служить опорой для моков и автоматической валидации контракта.

## Контекст применения

ЛК клиента ЮЛ отправляет запрос через API Gateway в `Сервис Договоров` (P14). `clientId`, реквизиты организации и шаблон договора в теле не передаются: сервер получает их из контекста авторизованной сессии, профиля клиента и опубликованного шаблона. Конкретный механизм аутентификации в контракте не закреплен.

Синхронная граница охватывает шаги 4–9 UC-8.2: система создает договор, формирует документ, передает его в ЭДО, получает `edoDocumentId`, переводит договор в `AWAITING_CLIENT_SIGNATURE` и инициирует уведомление. Таймаут ожидания подтверждения ЭДО — 30 секунд; при его превышении возвращается `502` по расширению `7а`. Ответ `201` подтверждает передачу документа в ЭДО, но не заключение договора.

Структуры всех тел формализованы в [JSON Schema — UC-8.2](schema-uc-8-2-create-contract.md). OpenAPI дополнительно определяет ответы `401` и `403`, для которых отдельные payload-примеры в этом документе не приводятся.

## Пример request body

```json
{
  "startDate": "2026-06-10",
  "endDate": "2027-06-10",
  "tariffId": 5,
  "vehicleIds": [1, 2, 3],
  "parkingPlaceIds": [15, 16, 17]
}
```

## Пример response — 201 Created

Договор создан, документ принят ЭДО и ожидает подписи клиента.

```json
{
  "contractId": 1024,
  "contractNumber": "DA-2026-0042",
  "status": "AWAITING_CLIENT_SIGNATURE",
  "startDate": "2026-06-10",
  "endDate": "2027-06-10",
  "tariffId": 5,
  "amount": 180000.0,
  "currency": "RUB",
  "vehicleIds": [1, 2, 3],
  "parkingPlaceIds": [15, 16, 17],
  "edoDocumentId": "edo-sbis-7f3a9c12",
  "createdAt": "2026-06-10T11:30:00Z"
}
```

## Пример response — 200 OK

По бизнес-ключу расширения `3а` найден существующий договор в нефинальном статусе.

```json
{
  "contractId": 880,
  "contractNumber": "DA-2025-0198",
  "status": "ACTIVE",
  "startDate": "2026-01-01",
  "endDate": "2026-12-31",
  "tariffId": 5,
  "amount": 120000.0,
  "currency": "RUB",
  "vehicleIds": [1, 2],
  "parkingPlaceIds": [15, 16],
  "edoDocumentId": "edo-sbis-1a2b3c4d",
  "createdAt": "2025-12-20T09:15:00Z",
  "alreadyExists": true
}
```

## Пример response — 400 Bad Request

```json
{
  "error_id": 400,
  "text_error": "Поле startDate не соответствует формату даты YYYY-MM-DD.",
  "details": {
    "field": "startDate"
  }
}
```

## Пример response — 422 Unprocessable Entity

```json
{
  "error_id": 422,
  "text_error": "У клиента не заполнены банковские реквизиты организации.",
  "details": {
    "field": "client.organization.bankRequisites"
  }
}
```

## Пример response — 502 Bad Gateway

```json
{
  "error_id": 502,
  "text_error": "ЭДО не подтвердил прием документа в течение настроенного таймаута.",
  "details": {
    "field": "edo.timeout"
  }
}
```

## Семантика полей

Поля запроса:

| Поле              | Тип              | Описание                                 | Источник      |
| ----------------- | ---------------- | ---------------------------------------- | ------------- |
| `startDate`       | string (`date`)  | Дата начала действия договора            | UC-8.2, шаг 1 |
| `endDate`         | string (`date`)  | Дата окончания действия договора         | UC-8.2, шаг 1 |
| `tariffId`        | integer          | Идентификатор тарифа долгосрочной аренды | UC-8.2, шаг 1 |
| `vehicleIds`      | array of integer | Идентификаторы ТС клиента                | UC-8.2, шаг 1 |
| `parkingPlaceIds` | array of integer | Идентификаторы закрепляемых машиномест   | UC-8.2, шаг 1 |

Поля успешного ответа:

| Поле              | Тип                     | Описание                                                       | Источник              |
| ----------------- | ----------------------- | -------------------------------------------------------------- | --------------------- |
| `contractId`      | integer                 | Идентификатор договора                                         | UC-8.2, шаг 4         |
| `contractNumber`  | string                  | Номер договора по правилу нумерации                            | UC-8.2, шаг 4         |
| `status`          | string (`enum`)         | Текущий статус договора                                        | UC-8.2, шаги 4, 8–14  |
| `startDate`       | string (`date`)         | Дата начала действия договора                                  | UC-8.2, шаги 1, 4     |
| `endDate`         | string (`date`)         | Дата окончания действия договора                               | UC-8.2, шаги 1, 4     |
| `tariffId`        | integer                 | Идентификатор примененного тарифа                              | UC-8.2, шаги 1–2      |
| `amount`          | number                  | Рассчитанная стоимость договора                                | UC-8.2, шаг 2         |
| `currency`        | string                  | Код валюты ISO 4217                                            | Расчет стоимости      |
| `vehicleIds`      | array of integer        | Идентификаторы ТС по договору                                  | UC-8.2, шаги 1, 4     |
| `parkingPlaceIds` | array of integer        | Идентификаторы машиномест по договору                          | UC-8.2, шаги 1, 4     |
| `edoDocumentId`   | string                  | Идентификатор принятого документа в ЭДО                        | UC-8.2, шаг 7         |
| `createdAt`       | string (`date-time`)    | Момент создания договора в UTC                                 | UC-8.2, шаг 4         |
| `alreadyExists`   | boolean, необязательное | `true`, если возвращен существующий договор по расширению `3а` | UC-8.2, расширение 3а |

Поля ошибки:

| Поле            | Тип                    | Описание                                    |
| --------------- | ---------------------- | ------------------------------------------- |
| `error_id`      | integer                | HTTP-код или внутренний числовой код ошибки |
| `text_error`    | string                 | Человекочитаемое сообщение                  |
| `details.field` | string, необязательное | Поле или предусловие, вызвавшее ошибку      |
