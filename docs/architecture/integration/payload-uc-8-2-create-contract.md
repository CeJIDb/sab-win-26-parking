# JSON-пример запроса — UC-8.2 Создание договора с ЮЛ

Документ фиксирует каноничный пример полезной нагрузки запроса на создание договора долгосрочной аренды с юридическим лицом для use case [UC-8.2](../../artifacts/use-case/uc-8-2-create-contract-legal-entity.md).

Пример используется как опора для реализации клиентской части (ЛК / PWA), серверной части `Сервиса Договоров` и автоматических проверок контракта.

## Назначение

Документ нужен, чтобы:

- зафиксировать согласованный формат запроса `POST /api/contracts` для UC-8.2;
- дать разработчику и QA каноничный пример для реализации и проверок;
- служить опорой для генерации мок-запросов в тестовых окружениях.

## Контекст применения

Запрос относится к шагам 1–4 основного потока UC-8.2: клиент ЮЛ указывает параметры аренды в форме «Создать договор» (шаг 1), подтверждает условия (шаг 3), после чего ЛК отправляет запрос, а система создает `[договор]` со статусом `черновик` (шаг 4).

Идентификатор клиента, реквизиты ЮЛ и шаблон договора в запросе не передаются: они определяются сессией, профилем клиента и опубликованным шаблоном долгосрочной аренды соответственно.

Формально структура описана в артефакте [JSON-схема запроса — UC-8.2](schema-uc-8-2-create-contract.md).

## Пример запроса

`POST /api/contracts`

```json
{
  "startDate": "2026-06-10",
  "endDate": "2027-06-10",
  "tariffId": 5,
  "vehicleIds": [1, 2, 3],
  "parkingPlaceIds": [15, 16, 17]
}
```

Пример описывает годовой договор: три ТС клиента закрепляются за тремя машиноместами по тарифу долгосрочной аренды.

## Семантика полей

| Поле              | Тип                     | Описание                                                                    |
| ----------------- | ----------------------- | --------------------------------------------------------------------------- |
| `startDate`       | string (date, ISO 8601) | Дата начала действия договора                                               |
| `endDate`         | string (date, ISO 8601) | Дата окончания действия договора                                            |
| `tariffId`        | integer                 | Идентификатор тарифа долгосрочной аренды (`tariffs`)                        |
| `vehicleIds`      | array of integer        | Идентификаторы ТС клиента (`vehicles`), на которые распространяется договор |
| `parkingPlaceIds` | array of integer        | Идентификаторы машиномест (`parking_places`), закрепляемых по договору      |
