# Реестр ошибок «Оплата»

Документ фиксирует перечень ошибок интеграции модуля `Платеж` с платежным провайдером (PSP), эквайрингом и ОФД. Реестр используется как опорная таблица для проектирования обработчиков ошибок, политики ретраев, идемпотентности и эскалации инцидентов в платежных сценариях.

## Назначение

Реестр нужен, чтобы:

- зафиксировать перечень типовых ошибок интеграции с платежным провайдером в одном месте;
- согласовать тип ошибки, место возникновения, рекомендуемые действия, критичность и уровень автоматизации;
- дать общую рамку для проектирования обработчиков в коде, политики ретраев и сценариев восстановления;
- поддержать применение требований к журналированию из [NFR-LOG-FIN-01](../../specs/nonfunctional-requirements/nfr-logging.md#43-финансовые-требования) и [NFR-LOG-TECH-01](../../specs/nonfunctional-requirements/nfr-logging.md#46-технические-требования).

## Границы реестра

Включено:

- ошибки конфигурации и инициализации клиента провайдера;
- ошибки запуска платежа, обработки webhook и сверки статуса;
- ошибки идемпотентности, валидации суммы и валюты;
- ошибки возвратов и частичных оплат;
- ошибки транспортного уровня (TLS, rate limit, circuit breaker);
- ошибки терминальной оплаты на КПП.

Не включено:

- ошибки фискализации в ОФД (выделены в отдельный сценарий и связаны через `INT-006`);
- ошибки SSO (см. [Реестр ошибок «SSO»](sso-errors-registry.md));
- бизнесовые отказы клиента вне канала оплаты (изменение брони, отмена сессии и пр.).

## Условные обозначения

- **Тип ошибки** — техническая (инфраструктура / транспорт / конфигурация), логическая (контракт / маппинг / валидация), бизнесовая (политика провайдера / клиента) или их сочетание.
- **Место возникновения (контекст)** — точка кода или UC-шаг, в котором ошибка обнаруживается.
- **Рекомендации** — действие по обнаружению ошибки (что делать сразу) и условия эскалации.
- **Критичность** — Критическая / Высокая / Средняя / Низкая. Используется для приоритизации обработчиков и мониторинга.
- **Уровень автоматизации** — `Полностью` (обработка без участия человека) или `Частично` (детект автоматический, исправление вручную).
