# JSON-пример ответа — UC-10.6 Получение платежного чека

Документ фиксирует каноничный пример полезной нагрузки ответа в сценарии получения платежного чека с данными связанного платежа для use case UC-10.6.

Пример используется как опора для реализации клиентской части (ЛК / PWA), серверной части сервиса фискализации и автоматических проверок контракта.

## Назначение

Документ нужен, чтобы:

- зафиксировать согласованный формат ответа для процесса UC-10.6;
- дать разработчику и QA каноничный пример для реализации и проверок;
- служить опорой для генерации мок-ответов в тестовых окружениях.

## Контекст применения

Ответ относится к процессу `UC-10.6 — Получить чек`. Он возвращается сервисом фискализации после формирования платежного чека по завершенному платежу. В корневой структуре расположены реквизиты чека, а вложенный объект `payment` содержит краткие сведения о связанном платеже.

Формально структура описана в артефакте [JSON-схема ответа — UC-10.6](schema-uc-10-6-receipt.md). Полный REST-контракт метода `GET /payments/{paymentId}/receipt` с HTTP-обвязкой и ветками ошибок описан в [OpenAPI-контракте REST-метода — UC-10.6](openapi-uc-10-6-receipt.md); этот документ остается фрагментом — каноничным примером успешного ответа `200`.

## Пример ответа

```json
{
  "receiptId": 4501,
  "paymentId": 7823,
  "fiscalNumber": "0001-0000-1234-5678",
  "receiptDateTime": "2026-05-10T14:32:00+03:00",
  "fiscalizationStatus": "FISCALIZED",
  "amount": 350.0,
  "payment": {
    "paymentId": 7823,
    "amount": 350.0,
    "currency": "RUB",
    "paymentMethod": "ONLINE_PERSONAL_ACCOUNT",
    "status": "SUCCESS",
    "initiatedAt": "2026-05-10T14:30:50+03:00",
    "completedAt": "2026-05-10T14:31:00+03:00",
    "paymentPurpose": "PARKING"
  }
}
```

## Семантика полей

| Поле                     | Тип                           | Описание                                                                                                               |
| ------------------------ | ----------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `receiptId`              | integer                       | Уникальный идентификатор чека во внутренней модели платформы парковки                                                  |
| `paymentId`              | integer                       | Идентификатор связанного платежа (совпадает с `payment.paymentId`)                                                     |
| `fiscalNumber`           | string                        | Фискальный номер чека, присвоенный ОФД                                                                                 |
| `receiptDateTime`        | string (date-time, ISO 8601)  | Момент формирования чека в часовом поясе `+03:00` (Europe/Moscow)                                                      |
| `fiscalizationStatus`    | string (enum)                 | Статус фискализации: `PENDING`, `FISCALIZED`, `ERROR` (маппинг: ОЖИДАНИЕ / ФИСКАЛИЗАЦИЯ / ОШИБКА)                      |
| `amount`                 | number                        | Сумма чека в валюте платежа, два знака после запятой, строго больше нуля                                               |
| `payment.paymentId`      | integer                       | Идентификатор платежа во внутренней модели платформы парковки                                                          |
| `payment.amount`         | number                        | Сумма платежа, два знака после запятой, строго больше нуля                                                             |
| `payment.currency`       | string                        | Код валюты в формате ISO 4217 (например, `RUB`)                                                                        |
| `payment.paymentMethod`  | string (enum)                 | Способ оплаты: `CARD_AT_TERMINAL`, `CARD_AT_GUARD`, `ONLINE_PERSONAL_ACCOUNT`, `AUTO_DEBIT`                            |
| `payment.status`         | string (enum)                 | Статус платежа: `INITIALIZED`, `SUCCESS`, `CANCELLED`, `ERROR` (маппинг: ИНИЦИАЛИЗИРОВАН / УСПЕШЕН / ОТМЕНЕН / ОШИБКА) |
| `payment.initiatedAt`    | string (date-time)            | Момент инициализации платежа                                                                                           |
| `payment.completedAt`    | string (date-time) или `null` | Момент завершения платежа; `null`, если платеж еще не завершен                                                         |
| `payment.paymentPurpose` | string (enum)                 | Назначение платежа: `PARKING`, `PENALTY`, `SUBSCRIPTION`, `OTHER` (маппинг: ПАРКОВКА / ШТРАФ / АБОНЕМЕНТ / ПРОЧЕЕ)     |
