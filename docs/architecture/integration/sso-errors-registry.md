# Реестр ошибок «SSO»

Документ фиксирует перечень ошибок интеграции модуля `Аутентификация` с внешним IdP (Яндекс ID, VK ID) по протоколу OAuth2 / OIDC. Реестр используется как опорная таблица для проектирования обработчиков ошибок, политики ретраев и эскалации инцидентов в сценариях входа через SSO.

## Назначение

Реестр нужен, чтобы:

- зафиксировать перечень типовых ошибок интеграции с IdP в одном месте;
- согласовать тип ошибки, место возникновения, рекомендуемые действия, критичность и уровень автоматизации;
- дать общую рамку для проектирования обработчиков потока OAuth2 / OIDC и сценариев восстановления;
- поддержать применение требований к журналированию из [NFR-LOG-SYS-02](../../specs/nonfunctional-requirements/nfr-logging.md#41-системные-требования-к-формату-и-контексту) и [NFR-LOG-SEC-01](../../specs/nonfunctional-requirements/nfr-logging.md#42-требования-к-безопасности-и-защите-пдн).

## Границы реестра

Включено:

- ошибки конфигурации клиента (`client_id`, `redirect_uri`, секреты);
- ошибки потока авторизации (CSRF-защита `state`, `nonce`, обмен кода на токен);
- ошибки валидации `id_token` (подпись, `iss`, `aud`, `exp` / `iat`, `sub`);
- ошибки получения профиля (`userinfo`);
- бизнесовые ошибки привязки и блокировки локального профиля;
- ошибки транспортного уровня (TLS, rate limit, circuit breaker).

Не включено:

- ошибки логина по паре «логин / пароль» в локальной БД;
- ошибки авторизации внутри платформы после установления сессии (RBAC);
- ошибки SSO для сотрудников (КПП, администрирование) — реестр покрывает потоки клиента ФЛ через Яндекс ID / VK ID;
- ошибки платежных интеграций (см. [Реестр ошибок «Оплата»](payment-errors-registry.md)).

## Условные обозначения

- **Тип ошибки** — техническая (инфраструктура / транспорт / конфигурация), логическая (контракт / валидация токена / CSRF) или бизнесовая (политика клиента / профиля).
- **Место возникновения (контекст)** — точка кода или шаг сценария, в котором ошибка обнаруживается.
- **Рекомендации** — действие по обнаружению ошибки (что делать сразу) и условия эскалации.
- **Критичность** — Критическая / Высокая / Средняя / Низкая. Используется для приоритизации обработчиков и мониторинга.
- **Уровень автоматизации** — `Полностью` (обработка без участия человека) или `Частично` (детект автоматический, исправление вручную).

## Реестр ошибок

| Код     | Тип ошибки  | Описание причины                                       | Место возникновения (контекст)               | Рекомендации (что делать)                                           | Критичность | Уровень автоматизации                                     |
| ------- | ----------- | ------------------------------------------------------ | -------------------------------------------- | ------------------------------------------------------------------- | ----------- | --------------------------------------------------------- |
| SSO-001 | Техническая | Не настроен `client_id` или `redirect_uri`             | Запуск входа через SSO                       | Проверить настройки провайдера и переменные окружения               | Критическая | Частично: найти можно автоматически, исправлять вручную   |
| SSO-002 | Техническая | Провайдер SSO выключен                                 | Старт входа через SSO                        | Включить провайдера в настройках или скрыть кнопку входа            | Средняя     | Частично: система может переключить на другой вход        |
| SSO-003 | Логическая  | В callback нет `state` или он не совпадает             | Возврат из IdP                               | Отклонить вход, очистить попытку и попросить войти заново           | Критическая | Полностью: система сама отклоняет                         |
| SSO-004 | Логическая  | `nonce` в токене не совпадает                          | Проверка `id_token`                          | Отклонить токен и начать новый вход                                 | Критическая | Полностью: система сама отклоняет                         |
| SSO-005 | Логическая  | В callback нет `code` и `error`                        | Возврат из IdP                               | Вернуть понятную ошибку и проверить настройки провайдера            | Высокая     | Полностью: система сама обрабатывает                      |
| SSO-006 | Бизнесовая  | Пользователь отменил вход (`access_denied`)            | Возврат из IdP                               | Завершить попытку и предложить попробовать снова                    | Низкая      | Полностью: система сама завершает                         |
| SSO-007 | Техническая | Истекло время ожидания ответа token endpoint           | Обмен `code` на `token`                      | Сделать повторные попытки, при неудаче показать временную ошибку    | Высокая     | Полностью: повторы и отказ автоматически                  |
| SSO-008 | Логическая  | IdP вернул `invalid_grant` (код невалиден / просрочен) | Обмен `code` на `token`                      | Завершить попытку и запустить вход заново                           | Средняя     | Полностью: перезапуск через новый вход                    |
| SSO-009 | Техническая | IdP вернул `invalid_client`                            | Обмен `code` на `token`                      | Проверить `client_id`, `client_secret` и настройки клиента          | Критическая | Частично: ошибка определяется автоматически               |
| SSO-010 | Логическая  | В ответе нет обязательного `id_token`                  | Чтение ответа token endpoint                 | Отклонить вход и проверить `scope openid` у провайдера              | Высокая     | Полностью: система сама отклоняет                         |
| SSO-011 | Логическая  | Неверная подпись `id_token`                            | Проверка JWT-токена                          | Заблокировать вход и проверить ключи провайдера                     | Критическая | Полностью: блокировка автоматически                       |
| SSO-012 | Логическая  | `iss` не совпадает с доверенным провайдером            | Проверка `id_token`                          | Отклонить токен и проверить адрес провайдера в настройках           | Критическая | Полностью: система сама отклоняет                         |
| SSO-013 | Логическая  | `aud` не содержит `client_id` системы                  | Проверка `id_token`                          | Отклонить токен и проверить регистрацию клиента у IdP               | Критическая | Полностью: система сама отклоняет                         |
| SSO-014 | Логическая  | Токен истек или еще не действует (`exp` / `iat`)       | Проверка времени токена                      | Отклонить токен, попросить войти снова, проверить время на серверах | Средняя     | Полностью: система сама отклоняет                         |
| SSO-015 | Логическая  | В ответе IdP нет обязательного `sub`                   | Связка IdP-пользователя с локальным профилем | Отклонить вход и проверить набор атрибутов от IdP                   | Высокая     | Полностью: отказ автоматически                            |
| SSO-016 | Бизнесовая  | Локальный профиль пользователя отключен                | Проверка пользователя перед созданием сессии | Не пускать в систему и отправить в поддержку                        | Средняя     | Частично: блок автоматически, разблокировка вручную       |
| SSO-017 | Бизнесовая  | Email / телефон уже заняты другим профилем             | Автопривязка аккаунта при первом входе       | Остановить автопривязку и передать на ручную проверку               | Высокая     | Частично: находит система, решает человек                 |
| SSO-018 | Техническая | Ошибка при создании локальной сессии                   | Создание сессии после успешного входа        | Откатить изменения, повторить 1 раз, затем вернуть ошибку           | Критическая | Частично: повтор автоматически, исправление вручную       |
| SSO-019 | Техническая | Недоступен `userinfo`, а данные обязательны            | Получение данных профиля из IdP              | Прервать вход или включить упрощенный режим по правилам             | Высокая     | Полностью: система действует по заданной политике         |
| SSO-020 | Техническая | Ошибка TLS / сертификата при запросе к IdP             | Защищенное соединение с IdP                  | Сразу остановить обмен и проверить сертификаты                      | Критическая | Частично: остановка автоматически, восстановление вручную |
| SSO-021 | Техническая | Слишком много попыток входа (rate limit)               | Защитный слой входа                          | Включить паузу (cooldown) и временно ограничить вход                | Средняя     | Полностью: лимиты работают автоматически                  |
| SSO-022 | Техническая | У IdP много 5xx / таймаутов, сработал circuit breaker  | Устойчивость интеграции                      | Временно отключить вход через провайдера до восстановления          | Критическая | Полностью: circuit breaker работает автоматически         |
