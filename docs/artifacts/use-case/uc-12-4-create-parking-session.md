## Метаданные

| Поле                 | Значение              |
| -------------------- | --------------------- |
| **Автор**            | Команда курса SAB     |
| **Название**         | Создать ПС            |
| **Действующее лицо** | Система               |

## Предусловия

- сценарий запущен как продолжение UC-12.1 «Пройти автоматическую идентификацию на въезде»;
- для ТС есть активное Бронирование.

## Триггер

ТС въезжает на парковку и выходит из зоны действия камер СКУД.

## Постусловие

- создана ПС, привязанная к Бронированию.

## Основной поток

1. Система принимает сообщение от СКУД:
   - тип события = «выезд из зоны»;
   - ГРЗ;
   - дату и время события;
   - идентификатор КПП;
   - идентификатор полосы.
2. Система создает ПС с атрибутами:
   - идентификатор;
   - Бронирование = ссылка на активное Бронирование ТС;
   - дата-время въезда;
   - КПП въезда = идентификатор КПП из сообщения от СКУД;
   - способ допуска = «автоматически»;
   - статус = «активна».
3. Система изменяет ПМ из Бронирования:
   - «Занято» = 1.
4. Система пересчитывает количество свободных мест.
5. Система передает количество свободных мест на Информационное табло.
6. Система актуализирует информацию о свободных местах:
   - на Сайте-визитке (Главная);
   - в ЛК клиента (раздел «Парковка»);
   - в Интерфейсе КПП (Панель КПП);
   - в ЛК управляющего и владельца (Главная).
7. Система завершает выполнение сценария.
