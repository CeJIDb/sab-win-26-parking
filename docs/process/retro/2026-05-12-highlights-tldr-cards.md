# Ретро: TL;DR-карточки highlights в README

**Связанный план:** [plans/2026-05-12-highlights-tldr-cards.md](../../../plans/2026-05-12-highlights-tldr-cards.md)

## 1. Задача

К каждому из 8 highlight-блоков в корневом `README.md` добавить раскрывающийся `<details>`-спойлер «Подробнее» с полями Контекст / Решение / Связанные артефакты — без правки самих файлов артефактов и `docs/specs/`.

## 2. Как решал

Сначала проведена параллельная верификация: 8 подагентов одновременно сверили числа и факты для каждого из 8 блоков с источниками. По итогам верификации выявлены расхождения с черновиком из плана:

- «учет» вместо «учёт» (конвенция «без ё»);
- «4 типа акторов» вместо 5 (источник: context-diagram.md);
- «10 систем» вместо «10+» (источник: context-diagram.md, раздел «Ключевые элементы»);
- «точки отсчета» вместо «отсчёта»;
- «6 акторам» вместо 5 в блоке FR Бронирование (источник: fr-booking.md);
- для блока A8 — «alt-блоки» вместо «break-блоки» (источник: файл sequence).

После верификации основной агент последовательно вставил 8 `<details>`-блоков в README.md с применением исправлений. Конвенция «без ё» применена к нескольким блокам (учет, отсчета, расчет стоимости).

## 3. Решил ли

Да. Все 8 `<details>`-спойлеров добавлены в `README.md`; файлы артефактов и `docs/specs/` не правились; `npm run ci:check` зеленый.

## 4. Эффективность

Параллельная верификация (8 подагентов) хорошо сработала для одновременной проверки числовых данных — сэкономила несколько итераций ручной сверки. Исправления вносились централизованно в основном агенте, что снизило риск конфликтов правок.

Узкое место — последовательная вставка 8 блоков одним агентом: занимает линейное время. В будущем можно рассмотреть параллельную вставку с разными агентами на разные блоки, если блоки не пересекаются по позициям в файле.

Черновые блоки в плане содержали несколько «ё» (учёт, отсчёта) — стоит сразу прописывать конвенцию «без ё» в шаблонах плана, чтобы не исправлять при вставке.

## 5. Как было и как стало

**До:** Каждый из 8 highlight-блоков README содержал только короткий TL;DR (1–2 строки) и ссылку «→ Открыть артефакт» — без контекста этапа, обоснования и связей с другими артефактами.

**После:** Каждый блок дополнен `<details>`-спойлером «Подробнее» с полями Контекст / Решение / Связанные артефакты; числа и формулировки сверены с источниками; TL;DR и ссылки на артефакты не изменены.
