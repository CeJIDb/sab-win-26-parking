# Ретро: Demo Days как мини-кейсы

**Дата:** 2026-05-13
**Длительность:** ~2 ч (6 параллельных агентов + финальный агент-верификатор)
**Связанный план:** [plans/2026-05-13-demo-days-mini-cases.md](../../../plans/2026-05-13-demo-days-mini-cases.md)
**Агент:** Claude Code (параллельные подагенты + финальный агент)

## 1. Задача

Привести 5 файлов `docs/demo-days/demo-N/readme.md` к единому шаблону (повестка + артефакты-источники + материалы выступления + связанные документы) и добавить витринный раздел «5 этапов / 5 demo» в корневой `README.md`.

## 2. Как решал

6 параллельных агентов одновременно перерабатывали по одному файлу (demo-1..5 + README). Перед правкой каждый агент сверял реальный состав артефактов через `test -f` и оглавление слайдов из `demo-N-presentation-deck.md`. По ходу выявлены несколько расхождений шаблона с реальностью:

- **demo-1**: BPMN-артефакты (bpmn-parking-exit, bpmn-bookings-parking-schema, bpmn-subscriptions-parking-schema) объединены в один пункт с bpmn-parking-exit как основным — остальные перечислены в описании.
- **demo-3**: Event Storming TO-BE упомянут в Повестке (слайды это подтверждают), но отдельного файла `es-tobe-as-is.md` для demo-3 нет — из артефактов-источников исключен, в Повестке оставлен как факт выступления.
- **demo-4**: секция «Содержимое каталога» с заглушками `slides/01.jpg`..`slides/33.jpg` удалена, добавлена ссылка на `slides/readme.md`; в Связанные документы добавлен 4-й пункт (`docs/architecture/readme.md`) — органично для этапа архитектуры.
- **demo-5**: слайды 6–30 (ретроспектива предыдущих 4 этапов) не включены в Повестку — только содержание Этапа 5, как предписывает шаблон.

Финальный агент прогнал CI-проверки, написал ретро, обновил roadmap.

## 3. Решил ли

Да, полностью. Все 5 файлов следуют единому шаблону; в README появился раздел «5 этапов / 5 demo»; CI зеленый.

## 4. Эффективность

Параллельный запуск 6 агентов ускорил выполнение примерно в 4 раза против последовательного. Риск конфликтов был минимален: агенты правили разные файлы. Ретро-агент получил все изменения уже готовыми — его задача сводилась к верификации и финализации. Журнал трассировки не трогался осознанно: все изменения навигационные, требования и артефакты-источники не менялись — это зафиксировано в плане и в «Итоге» плана.

## 5. Как было и как стало

**До:** 5 файлов `demo-N/readme.md` — разнобой структур (у demo-1/2/3 — мертвые секции «Рекомендуемое развитие», у demo-4 — заглушки слайдов, у demo-5 — наиболее свежий формат). Корневой README без процессного среза.

**После:** 5 файлов следуют одному шаблону (повестка → артефакты → материалы → связанные документы). Корневой README содержит таблицу «5 этапов / 5 demo» между разделами «8 ключевых артефактов» и «Команда». CI чистый.
