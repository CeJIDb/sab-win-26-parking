# Ретро: EN-расширение портфолио

**Дата:** 2026-05-13
**Длительность:** ~30 мин (оркестратор + 2 параллельных агента)
**Связанный план:** [plans/2026-05-13-en-extension.md](../../../plans/2026-05-13-en-extension.md)
**Агент:** Claude Code (оркестратор + worktree-агенты A и B)

## 1. Задача

Создать полноценную EN-витрину `README.en.md`, добавить языковой переключатель в RU `README.md` и удалить устаревший inline-блок «English Summary» из RU README.

## 2. Как решал

Оркестратор прогнал Фазу 0 (сверка ветки, наличия файла, Netlify-ссылки, команды), затем одним сообщением запустил два параллельных под-агента в изолированных worktree: агент A создавал `README.en.md` по mock-up'у плана, агент B вносил switcher и удалял English Summary из `README.md`. После получения отчётов — копирование файлов в основное дерево, ZWSP-проверка, Prettier, `npm run ci:check`. Все проверки прошли с первого раза.

## 3. Решил ли

Да, полностью. Все фазы 0–6 выполнены, ci:check зеленый, ретро написано.

## 4. Эффективность

Параллельный запуск агентов через `isolation: "worktree"` сработал без конфликтов — разные файлы, разные worktree. Точное разделение scope в промтах агентов (A не трогает README.md, B не создает README.en.md) устранило риск мержевого конфликта на уровне архитектуры задачи, а не постфактум.

**Drift-стратегия — ручная, дополнительной автоматизации не вводим.** Контроль расхождения RU/EN остается на дисциплине автора. Причина: витринная пара файлов, не основной контент; ручной контроль через roadmap-правило «8 highlights — single source» достаточен.

**Правило для будущих правок:** любая правка метрики «80% за 6 месяцев» в разделе Problem/Solution/Goal RU README **обязана** синхронизироваться в `README.en.md` в том же коммите. Без автоматического линтера это держится исключительно на дисциплине автора.

**Риск навигационного якоря:** `README.en.md` ссылается на `docs/readme.md#с-чего-начать`. При переименовании заголовка `## С чего начать` упадут оба README одновременно — это поймает `lint:md-links` на pre-push, но автор переименования должен быть готов исправить два файла.

**Журнал трассировки не трогался** — правки затронули только корневые витринные README, требования, артефакты и архитектурные решения не изменялись.

## 5. Как было и как стало

**До:** корневой `README.md` с inline-блоком `## English Summary` (~12 строк bullet-перевода lifecycle) в хвосте; никакого переключателя языка.

**После:** `README.en.md` — 88 строк, полноценная EN-витрина (hero, problem/solution/goal, 8 highlights, 5 demo, team, navigation, stack, wireframe); в `README.md` — language switcher между H1 и бейджами, английский хвост удален.
