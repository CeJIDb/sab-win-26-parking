# Ретро: чистка следов Cursor из репозитория

**Дата:** 2026-05-12
**Длительность:** ~25 мин
**Связанный план:** [plans/2026-05-12-cleanup-cursor-traces.md](../../../plans/2026-05-12-cleanup-cursor-traces.md)
**Агент:** Claude Code

## 1. Задача

Удалить из репозитория все артефакты Cursor (каталог `.cursor/`, документ `cursor-agent-commands.md`, папку `evals/`) и снять упоминания инструмента в 11 файлах: 4 корневых .md, 2 файла docs/process/, 4 скрипта, `.claude/settings.json`.

## 2. Как решал

Координатор выполнил физическое удаление через `git rm` до запуска агентов — это позволило агентам работать на «постудалённом» дереве и сразу проверять корректность ссылок. Затем запустил 4 агента параллельно с непересекающимися скоупами: агент A — корневые .md, агент B — docs/process/, агент C — скрипты, агент D — `.claude/settings.json`. Все 4 агента вернули результат в одном раунде без переработки.

## 3. Решил ли

Да. Все пункты DoD подтверждены локально:

- `grep -i cursor` по 11 файлам — 0 совпадений.
- `npm run ci:check` — зеленый.
- `npm run lint:md-links` — зеленый.
- `node scripts/git-workflow-agent-reminder.mjs` — работает без cursor-ссылок.
- Защищенные файлы (traceability-matrix-log.md, retro/README.md, .gitignore) — не тронуты.

## 4. Эффективность

Параллельный запуск 4 агентов с жестко разделенными скоупами сработал без коллизий. Ключевое решение — делать `git rm` до агентов, а не после: так линтер ссылок не ловит ложные тревоги на уже-удаленные файлы. Порядок коммитов из плана (сначала удаление, потом скрипты) сохраняет работоспособность `atomic-commit.mjs` в момент первого коммита — это стоит повторять в подобных «удалить + отвязать» сценариях.

## 5. Как было и как стало

**До:** 34 файла в `.cursor/` + `docs/process/cursor-agent-commands.md` + `evals/` (2 файла); упоминания Cursor в 11 файлах проекта; deny-правила в `.claude/settings.json` и cursor-bucket в `atomic-commit.mjs`.

**После:** `.cursor/`, `evals/` и `cursor-agent-commands.md` отсутствуют; все 11 целевых файлов чисты; инфраструктура Claude Code и скрипты работают штатно.
