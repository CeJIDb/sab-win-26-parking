# Ретро: Фаза 5 — REST payload и JSON Schema для UC-8.2

**Дата:** 2026-08-20
**Длительность:** несколько рабочих сессий с 2026-06-10
**Связанный план:** [мастер-план UC-8.2](../../../plans/2026-05-02-uc-8-2-edo-integration.md), раздел «Фаза 5 завершена 2026-08-20». Закрытый подплан удален.
**Агент:** Codex и пользователь

## 1. Задача

Завершить REST-контракт `POST /api/v1/contracts` для UC-8.2: дополнить request-артефакты примерами успешных и ошибочных ответов, собрать единую JSON Schema и синхронизировать планы.

## 2. Как решал

Request-пример и его standalone-схема были подготовлены раньше. Для завершения фазы из закрытой страницы BuildIn выгружены структуры `ContractResponse` и `ProblemResponse`, а также примеры ответов `201`, `200`, `400`, `422` и `502`. Ответы перенесены в `payload-*`, а схема преобразована в контейнер draft 2020-12 с тремя `$defs`.

При сверке обнаружилось расхождение технических статусов: BuildIn и UC-8.2 используют семантику парковки, ERD — имя Владельца. По актуальному UC каноничными выбраны `AWAITING_PARKING_SIGNATURE` и `REJECTED_BY_PARKING`; OpenAPI, JSON Schema, ERD и планы синхронизированы.

Каждый из шести примеров извлечен во временный каталог и проверен через `ajv-cli@5` с `ajv-formats` против соответствующего `$defs`.

## 3. Решил ли

Да. Payload содержит request и пять response-примеров, JSON Schema содержит `ContractCreateRequest`, `ContractResponse` и `ProblemResponse`, все примеры валидны. Фаза 5 и ее подплан закрыты; мастер-план и журнал трассировки актуализированы.

## 4. Эффективность

Сработала поэтапная проверка источника: сначала восстановление точной структуры BuildIn, затем перенос в OpenAPI и только после этого выделение переиспользуемых payload/schema-артефактов. Wrapper-схемы для отдельных `$defs` сделали проверку однозначной.

Можно было раньше сверить enum с формулировками самого UC-8.2. Это сняло бы промежуточную пометку об открытом расхождении и сократило число повторных правок планов.

## 5. Как было и как стало

| Состояние        | До                                                 | После                                                                  |
| ---------------- | -------------------------------------------------- | ---------------------------------------------------------------------- |
| `payload-*`      | Только request                                     | Request и ответы `201`, `200`, `400`, `422`, `502`                     |
| `schema-*`       | Standalone-схема request                           | Draft 2020-12 контейнер с тремя `$defs`                                |
| Статусы договора | `*_PARKING` в BuildIn, `*_OWNER` в ERD             | Единый enum `*_PARKING` по UC-8.2                                      |
| Фаза 5           | Частично завершена, response-контракт не перенесен | Завершена; шесть примеров проверены ajv, планы и трассировка обновлены |
