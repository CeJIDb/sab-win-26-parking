# Demo 4 — Архитектура

Четвертое демо закрывает этап архитектурного проектирования: команда показала анализ угроз безопасности, декомпозицию системы на bounded contexts, C4-диаграммы и нормализованную ER-модель.

## Повестка

- Анализ угроз информационной безопасности методом «галстук-бабочка»: риски, превентивные и реактивные барьеры
- ES TO-BE с выделенными доменными контекстами (Core, Supporting, Generic)
- Сравнение архитектурных подходов и обоснование выбора; C4-диаграммы (контекст, контейнеры, компоненты)
- Нормализованная ER-модель и выбор СУБД; примеры SQL-запросов по доменам

## Артефакты-источники

- [Анализ угроз: галстук-бабочка](../../artifacts/infosec/bow-tie-unauthorized-access-to-system-and-data.md) — моделирует угрозу несанкционированного доступа с барьерами на обеих сторонах события.
- [ES TO-BE с выделенными контекстами](../../architecture/ddd/es-tobe-sd-contexts.md) — определяет границы bounded contexts и служит основой для C4-декомпозиции.
- [C4-диаграммы](../../architecture/c4/c4-diagrams.md) — показывает систему на уровнях контекста, контейнеров и компонентов.
- [Нормализованная ER-модель](../../architecture/database/erd/erd-normalized-er-model.md) — схема базы данных в нормальной форме с разбивкой по доменам.
