# Demo 3 — Функциональное проектирование решения

На третьем демо команда представила результаты функционального проектирования: от Event Storming To-Be до контекстной диаграммы, реестра Use Case, навигационной карты интерфейсов и концептуальной модели данных.

## Повестка

- Event Storming To-Be: основной поток, въезд/КПП, сравнение AS-IS и TO-BE
- Контекстная диаграмма: границы системы, ключевые пользы, внешнее окружение и потоки данных
- Use Case: диаграмма, реестр, пример описанного UC, CRUDL-анализ
- Пользовательские интерфейсы: навигационная карта и макеты экранов
- Концептуальная модель данных и словарь сущностей
- Функциональные и нефункциональные требования
