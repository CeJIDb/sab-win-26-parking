# Demo 2 — Концептуальное проектирование решения

На втором демо команда представила результаты концептуального этапа: от целей и воздействий через возможности решения до пользовательских сценариев и состава MVP.

## Повестка

- Контекст и результаты исследования бизнеса
- Impact Map: цель, акторы, ключевые воздействия и решения
- Opportunity Canvas: идеи решений, ценность, метрики, бюджет и требования к качеству
- User Story Map: ключевые сценарии пользователей и состав MVP
- Сложности этапа и заключение

## Артефакты-источники

- [Impact Map](../../artifacts/impact-map.md) — связывает цель проекта с акторами, воздействиями и поставками.
