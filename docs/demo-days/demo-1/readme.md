# Demo 1 — Исследование бизнеса заказчика (AS-IS)

Первое демо фиксирует результаты исследования текущего состояния паркинга: выявленные процессы, их недостатки и модель предметной области до старта проектирования решения.

- [Артефакты-источники](#артефакты-источники)
- [Материалы выступления](#материалы-выступления)
- [Связанные документы](#связанные-документы)

## Повестка

- Контекст проекта и текущая ситуация на паркинге
- Event Storming AS-IS — визуализация хаоса и выявление ключевых процессов
- Моделирование бизнес-процессов BPMN: въезд/выезд, идентификация, подписание договора, оплата
- Выявленные недостатки AS-IS и выводы по итогам анализа
- Моделирование предметной области (UML Class) и состояний договора (State Machine)
- Opportunity Canvas и Problem Statement

## Артефакты-источники

- [Event Storming AS-IS](../../artifacts/as-is/event-storming-as-is.md) — карта доменных событий текущего состояния паркинга; основа для выявления узких мест и формулировки проблем.
- [BPMN-процессы AS-IS](../../artifacts/as-is/bpmn-parking-exit.md) — формализованные процессы въезда/выезда, идентификации клиента, подписания договора и оплаты (bpmn-parking-exit, bpmn-client-identification, bpmn-contract-signing, bpmn-payment-individual-and-legal-clients).
- [UML Class — доменная модель AS-IS](../../artifacts/as-is/uml-class-domain-as-is.md) — структура сущностей и связей предметной области до проектирования решения.
- [UML State — договор с физическим лицом](../../artifacts/as-is/uml-state-contract-with-individual.md) — машина состояний договора; показывает жизненный цикл ключевой сущности.
